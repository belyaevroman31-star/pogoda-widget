# Погода — виджет по среднему из 3 сервисов

Мобильный (PWA) виджет погоды, который **запрашивает прогноз сразу у трёх популярных**
метеосервисов, **усредняет показания** и показывает результат — большое «среднее»
значение температуры, влажности, ветра, давления, видимости и облачности, а также:

- 🌧 **предупреждения о дожде/снеге** с точным временем начала (и окончания),
- 🌫 предупреждение о **тумане**,
- 🧊 предупреждение о **гололедице** (осадки при минусовой температуре),
- 🗺 интерактивную **мини-карту осадков** (радар, анимация по кадрам),
- 📤 кнопку **«Поделиться»** (QR-код, ссылка, системный шер).

Среднее считается по «живым» данным **Open-Meteo**, **OpenWeatherMap** и **WeatherAPI.com**.
Если сервис недоступен — он просто пропускается, и среднее пересчитывается по остальным
(количество учтённых источников видно на карточке).

---

## Возможности

| Функция | Детали |
|---|---|
| Среднее по 3 сервисам | температура, ощущается, влажность, ветер, давление, видимость, облачность, осадки |
| Почасовой прогноз | горизонтальная лента на ~36 часов, усреднённый, с вероятностью осадков |
| Предупреждения | дождь/снег (время начала/конца), туман, гололедица — по правилу большинства сервисов |
| Карта осадков | радар RainViewer + анимация, слайдер кадров, ваша точка на карте |
| Геолокация | автоопределение при первом запуске + кнопка 📡 |
| Поиск города | автодополнение по Open-Meteo geocoding |
| PWA | устанавливается на Android/iOS, работает офлайн со свежим кэшем |
| Тёмная тема 2026 | стеклянные карточки, mesh-градиенты, bottom-sheets |

---

## Как это работает

1. Берётся геолокация (или выбранный город).
2. Параллельно опрашиваются 3 API (у каждого своя нормализация погодных кодов).
3. Каждый час прогноза попадает в «корзину» по времени, внутри неё числовые поля
   усредняются, а осадки считаются по **правилу большинства**: если ≥2 сервисов из 3
   (или ≥½ из доступных) прогнозируют дождь в этот час — ставится флаг «дождь».
4. По последовательности часовых флагов ищутся интервалы → генерируются предупреждения
   с временем начала. Туман = флаг тумана/видимость. Гололедица = осадки при ≤ +0,7 °C
   или прямой код «переохлаждённых» осадков.

## 🚀 Быстрый старт (локально)

Никаких сборок не нужно — это чистые HTML/CSS/JS.

```bash
# из папки проекта
python -m http.server 8000
# откройте http://localhost:8000
```

Достаточно **одного ключа OpenWeatherMap** (или вообще без ключей — тогда будет работать
только Open-Meteo) → нажмите ⚙ и впишите ключи.

| Сервис | Ключ | URL для получения | CORS в браузере |
|---|---|---|---|
| Open-Meteo | не нужен | — | ✅ (официально, бесплатно) |
| OpenWeatherMap | `appid` | https://openweathermap.org/api | ✅ |
| WeatherAPI.com | API key | https://www.weatherapi.com | ❌ нужен прокси |

---

## 🔑 Получение ключей

1. **OpenWeatherMap**: зарегистрируйтесь → `API keys` → скопируйте ключ (бесплатный
   тариф — 1000 запросов/день, хватает на часы).
2. **WeatherAPI.com**: зарегистрируйтесь → `My account` → скопируйте ключ
   (бесплатно — 1 000 000 запросов/месяц).

> Ключи хранятся только в `localStorage` вашего браузера и уходят только в сами сервисы.
> При отправке на GitHub **не** попадают в историю.

## 🌐 WeatherAPI и CORS (шаг, который нужен только для 3-го сервиса)

WeatherAPI.com не отдаёт браузеру заголовок `Access-Control-Allow-Origin`, поэтому из
чистого фронтенда его нельзя позвать напрямую. Решение — свой бесплатный прокси на
**Cloudflare Workers** (в репозитории уже лежит готовый файл: `proxy/worker.js`).

1. Зайдите на https://dash.cloudflare.com → Workers & Pages → **Create Worker**.
2. Удалите демо-код и вставьте содержимое `proxy/worker.js` → **Deploy**.
3. Скопируйте URL вида `https://имя-ваше.workers.dev`.
4. В приложении: ⚙ → поле «CORS-прокси» → вставьте
   `https://имя-ваше.workers.dev?url={url}` → «Сохранить и обновить».
5. Нажмите «🧪 Проверить прокси» — должно появиться «✓ Прокси работает».

Прокси принимает любой параметр `url=` и лишь добавляет CORS-заголовки — ключ
WeatherAPI уходит в прокси зашифрованным по HTTPS и дальше в WeatherAPI (прокси его
«не видит» в логике, работает как простой ретранслятор).

Если прокси не нужен — режим запросов «Только напрямую», WeatherAPI просто
пропускается, и среднее считается по двум источникам.

## 📦 Публикация на GitHub (чтобы можно было установить на Android)

PWA можно ставить только с **HTTPS**, поэтому просто откройте репозиторий как GitHub
Pages — это бесплатный хостинг с HTTPS.

Способ А — загрузить файлы через веб:
1. Создайте репозиторий (https://github.com/new), например `pogoda-widget`.
2. **Uploading an existing file** → перетащите всё содержимое папки (обязательно
   `index.html`, `manifest.json`, `sw.js`, папки `css`, `js`, `icons`, `proxy`).
3. Commit ✔.
4. `Settings → Pages → Source: Deploy from a branch → main → Save`.
5. Через минуту приложение будет на `https://<ник>.github.io/pogoda-widget/`.

Способ Б — через git:
```bash
cd "путь к папке погода"
git init
git add .
git commit -m "Мобильный виджет погоды (PWA)"
git branch -M main
git remote add origin https://github.com/<ник>/pogoda-widget.git
git push -u origin main
```
Дальше так же: `Settings → Pages → Deploy from branch main → Save`.

> URL приложения станет: `https://<ник>.github.io/<репозиторий>/`

## 📱 Установка на Android

1. Откройте ссылку приложения в **Chrome** (Android).
2. Нажмите меню «⋮» → **«Добавить на главный экран» / «Установить приложение»**
   (или если Chrome предложит баннер «Установить» — жмите его).
3. Готово — иконка **Погода** на рабочем столе, открывается на весь экран, работает
   со свежим кэшем даже без сети (показывается последний успешный прогноз).

Требования для установки уже выполнены: `manifest.json`, иконки 192/512, сервис-воркер.

На iOS (Safari): «Поделиться» → «На экран „Домой“».

## 📤 Как поделиться приложением с другими людьми

В приложении есть кнопка **📤 «Поделиться»**. Она открывает меню:

1. **QR-код** — покажите экран тому, кто рядом: он наводит камеру и открывает
   приложение за 2 секунды.
2. **Отправить через…** — системное меню Android/iOS: сообщение, Telegram, WhatsApp, e-mail.
3. **Скопировать ссылку** — вставьте в любой чат.

Плюс **быстрая инструкция для получателя** (отправьте вместе со ссылкой):

> «Открой ссылку в Chrome на Android. Нажми ⋮ → **Установить приложение** —
> будет как обычное приложение, с прогнозом по среднему из 3 сервисов и радаром осадков.
> Если не захочешь давать 2 ключа — заработает и так, только источников будет меньше.»

Советы:
- Ссылка вида `https://<ник>.github.io/pogoda-widget/` — короче всего, удобно для QR.
- Можно создать короткие ссылки через сторонние сервисы (например, bit.ly).
- Если человеку нужен **полный доступ ко всем 3 сервисам**, он должен вставить свои
  ключи в настройках (настройки у каждого свои — они не шаредятся).

## ⚠ Примечания и ограничения

- **Правило большинства**: если из 3 сервисов дождь прогнозируют только 1, предупреждение
  не выводится (это защита от ложных срабатываний). При 1 доступном сервисе его голос — решающий.
- Карта осадков RainViewer покрывает большинство регионов; без данных радара показывается
  соответствующее сообщение. Карта требует интернета (Leaflet и тайлы с CDN).
- Публичные CORS-прокси (allorigins, corsproxy.io) сейчас нестабильны/платные —
  поэтому свой прокси в репозитории. Open-Meteo и OpenWeatherMap работают без него.
- GitHub Pages кэширует на 10 минут; при обновлении приложения ключи и город сохраняются.
